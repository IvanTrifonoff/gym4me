# openGym Next

Новая модульная версия openGym. Создаётся параллельно с production `/opt/opengym`.

## Статус

Безопасный архитектурный каркас. Пока не подключён к production-БД, домену или production-портам.

## Домены

| Домен | Ответственность |
|---|---|
| `gym` | организация, филиалы, сотрудники, роли, настройки сети |
| `trainer` | профиль тренера, спортсмены, рабочие часы |
| `athlete` | профиль, программы, тренировки, история, кастомные упражнения |
| `bookings` | заявки, записи, статусы, конфликты расписания |
| `loyalty` | события, правила, баллы, награды |
| `notifications` | центр уведомлений, push, badge, outbox |
| `analytics` | read-only статистика |
| `integrations` | webhook и внешние системы |

## Правила

- modular monolith, а не преждевременные микросервисы;
- один владелец данных для каждой сущности;
- междоменные операции только через публичные сервисы и события;
- frontend не обращается напрямую к чужим таблицам;
- вторичные эффекты не откатывают успешную бизнес-операцию;
- legacy endpoint остаются адаптерами во время миграции.

## Запуск

Пока намеренно не настроен. Следующий этап — минимальный API на отдельном порту `3100` без production credentials.
