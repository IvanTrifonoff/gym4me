# Изоляция сбоев

## Подтверждение записи

Критическая транзакция:

1. проверить actor и policy;
2. проверить принадлежность тренеру;
3. проверить статус;
4. проверить конфликт слота;
5. изменить booking;
6. commit.

Вторичные эффекты после commit:

- app notification;
- push;
- badge;
- analytics projection.

Если push недоступен, booking всё равно остаётся подтверждённым. Push повторяется через outbox.

## Запреты

Нельзя отправлять push внутри SQL-транзакции booking, передавать тренеру полный AthleteState или позволять manager обходить branch policy.
